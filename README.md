# 🛒 Amazon Clone

A responsive Amazon homepage clone built using HTML5 and CSS3. This project recreates the basic layout and user interface of Amazon's homepage, focusing on responsive design and clean styling.

## ✨ Features

- Responsive Navigation Bar
- Search Bar
- Hero Section
- Product Categories
- Shopping Cards
- Footer
- Mobile-Friendly Layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
amazon-clone/
│── index.html
│── style.css
│── README.md
└── images/
```

## 🚀 How to Run

1. Clone this repository.
2. Open `index.html` in your web browser.
